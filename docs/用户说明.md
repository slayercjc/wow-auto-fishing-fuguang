# 魔兽世界钓鱼助手使用手册

## 一、使用前准备

1. 将软件完整解压到一个文件夹，不要直接在压缩包内运行。
2. 打开游戏，让人物站在可以钓鱼的位置，面向水面。
3. 把钓鱼技能放到快捷键 **1**，确认手动按 1 能正常抛竿。
4. 打开游戏声音，确保能听到咬钩音效。尽量关闭音乐、视频等干扰声音。
5. 双击 `FishingLearned.exe` 打开助手，使用过程中保持网络连接。

## 二、首次使用：校准鱼漂

1. 点击 **校准鱼漂**。
2. 在屏幕提示的 **5 秒倒计时**内切回游戏，鼠标移离鱼漂附近。
3. 软件会自动按 1 抛竿。保持游戏在前台，不要切换或移动游戏窗口。
4. 约 3 秒后弹出截图，用鼠标左键拖动，框住完整鱼漂，尽量不要框入文字和大片水面。
5. 可以滚动鼠标滚轮放大查看；框选后，单击浮子中心调整收鱼位置。
6. 按 **Enter** 确认，按 **Esc** 取消。
7. 看到“校准完成”和“样本已就绪”后，继续测试定位。

改变视角、游戏窗口大小，或鱼漂外观明显变化后，建议重新校准。

## 三、测试定位

1. 点击 **测试定位**。
2. 在 **5 秒倒计时**内切回游戏。
3. 软件自动抛竿，请不要手动移动鼠标。
4. 定位成功后会显示绿色成功提示，并自动停止测试。
5. 若提示失败，请重新校准，再测试一次。

测试定位成功后，再点击开始钓鱼。

## 四、开始与停止

1. 点击 **开始钓鱼**。
2. 在 **4 秒倒计时**内切回游戏，保持游戏在前台。
3. 软件会自动抛竿、寻找鱼漂、等待咬钩并收鱼。
4. 收鱼后会等待 1–3 秒，再次抛竿；一竿等待约 30 秒仍未完成，会重新抛竿。
5. 运行期间不要手动移动鼠标或切换游戏窗口。需要操作电脑时，先停止软件。
6. 按 **F10** 可随时停止，也可以点击软件上的 **停止** 按钮。

运行期间人物可能定时跳一下，属于正常行为。

## 五、调整声音阈值

默认 **74%**，建议先使用默认值。

- 没有咬钩却提前收鱼：适当调高。
- 明明听到咬钩却不收鱼：确认游戏声音正常，再适当调低。
- 每次调整 1–2%，观察几竿再决定是否继续调整。

鼠标悬停在“声音阈值”旁的问号上，可查看说明。下面的声音电平用于观察软件是否收到声音；有声音时通常会变化。

## 六、试用和激活

未激活时可累计试用半小时。需要激活时：

1. 点击软件底部的 **激活**。
2. 点击 **复制硬件码**，发送给管理员。
3. 收到激活码后，粘贴到激活窗口，点击 **联网激活**。
4. 确认显示正确的授权状态后使用。

30 天授权从首次激活开始计算，另有终身授权。激活码仅适用于对应电脑，使用时仍需联网。

## 七、查看记录和更新

- 点击 **运行记录** 打开记录窗口，再点一次关闭。遇到问题可把提示截图发给管理员。
- 点击 **检查更新** 查看是否有新版。
- 下载完成后，先退出软件，再将更新包解压到原目录覆盖。
- 更新时保留原来的 `demo.xml` 文件，不要删除自己的校准资料。

## 八、常见问题

**提示“样本未就绪”**：先完成校准鱼漂，再测试定位。

**鼠标没有准确移到鱼漂**：停止运行，重新框选鱼漂并单击浮子中心，之后再测试。

**点击开始后没有动作**：确认已在倒计时内切回游戏，钓鱼技能放在快捷键 1，网络和授权状态正常。

**提示 F10 被占用**：关闭其他已打开的助手或占用该快捷键的程序，再重新启动。

**切换窗口后停止**：切回游戏后重新点击开始钓鱼，并按提示完成倒计时。

**提示样本缺失或损坏**：先保留原文件夹，再重新解压完整软件包并校准；仍有问题联系管理员。

**软件文件如何保留**：不要只移动 EXE，请保留整个软件文件夹。`demo.xml` 保存使用所需的样本和校准资料，请勿删除；`log.txt` 是运行记录，退出软件后可以删除，之后运行会重新生成。
